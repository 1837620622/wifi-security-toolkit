# 目录结构（与 GitHub 发布同步）

> 仓库名：`wifi-security-toolkit`  
> 远端：https://github.com/1837620622/wifi-security-toolkit  
> **本地顶层文件夹名称必须与下表一致，勿再使用已废弃的 `windows/`。**

## 1. GitHub 已发布（可 clone 得到）

```text
wifi-security-toolkit/                 # 仓库根
├── README.md
├── .gitignore
├── .gitattributes
│
├── docs/                              # 文档
│   ├── 00-目录结构.md                 # 本文件
│   ├── 01-抓包教程.md
│   ├── 02-推荐工具.md
│   ├── 03-字典与握手包目录.md
│   └── assets/                        # SVG 示意图
│
├── shared/                            # 跨平台共享入口
│   ├── README.md
│   ├── dicts -> ../wifi-crack-notebook/dicts   # 符号链接
│   ├── captures/                      # 默认握手包目录（.gitkeep）
│   └── captures_legacy -> ../wifi-crack-notebook/captures
│
├── mac/                               # macOS / Apple Silicon 专用
│   ├── README.md
│   ├── crack.sh
│   └── monitor.sh
│
├── win/                               # Windows GPU 专用（目录名 win，不是 windows）
│   ├── README.md
│   ├── crack.ps1
│   └── crack.bat
│
├── wifi-crack-kali/                   # Kali 空口抓包 / 攻击
│   ├── 扫描抓包/                      # 1_scan · 2_capture · 3_deauth
│   ├── 自动攻击/                      # auto_attack.py
│   └── 字典工具/                      # generate_cn_dict.py
│
└── wifi-crack-notebook/               # 破解引擎 + 云脚本 + 字典实体
    ├── crack_local.sh                 # Mac 引擎（支持 --hash/--dict-dir）
    ├── crack_cloud.sh
    ├── cloud_start.sh / cloud_monitor.sh / cloud_stop.sh
    ├── monitor.sh
    ├── crack_xiaomi_a380.sh / crack_xiaomi_a380_resume.sh
    ├── gen_isp_dict.py / gen_xiaomi_a380.py
    └── dicts/                         # 字典与规则真实存放处
```

## 2. 命名对照（强制）

| 正确名称 | 错误/废弃 | 用途 |
|----------|-----------|------|
| `mac/` | — | Apple Metal 入口 |
| `win/` | ~~`windows/`~~ | Windows CUDA/OpenCL 入口 |
| `shared/` | — | 字典链接 + 握手默认目录 |
| `wifi-crack-kali/` | — | 抓包侧 |
| `wifi-crack-notebook/` | — | 爆破引擎与字典实体 |
| `docs/` | — | 说明文档 |

## 3. 仅本地存在（不入 Git，运行时生成）

| 路径 | 说明 |
|------|------|
| `mac/work/` | Mac 运行 potfile / 临时文件 |
| `win/work/` | Windows 运行产物 |
| `wifi-crack-notebook/work/` | 旧入口 / 云脚本工作区 |
| `wifi-crack-notebook/captures/` | 历史握手包（可由 `shared/captures_legacy` 访问） |
| `wifi-crack-notebook/hashes/` | 可选哈希目录 |
| `wifi-crack-notebook/dicts/cn-sources/` | 新下载大字典源（gitignore） |
| `wifi-crack-notebook/dicts/15-mega160m.txt` 等 | 巨型本地字典（gitignore） |
| `wifi-crack-kali/结果/` | 抓包输出 |
| `**/__pycache__/` | Python 缓存 |

## 4. 字典路径约定

| 用途 | 路径 |
|------|------|
| 脚本默认读取 | `shared/dicts/`（链接到 notebook/dicts） |
| 实体文件 | `wifi-crack-notebook/dicts/` |
| 新下载不重名存放 | `wifi-crack-notebook/dicts/cn-sources/latest/` |
| 默认握手 | `shared/captures/` 或 `shared/captures_legacy/` |
