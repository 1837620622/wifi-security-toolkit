# 字典与握手包目录说明

## 总览

```text
仓库根/
├── shared/                          ★ 跨平台共享（优先用这里）
│   ├── dicts/          → 符号链接到 wifi-crack-notebook/dicts
│   ├── captures/                    默认放入握手包
│   ├── captures_legacy → 旧 captures 链接
│   └── README.md
├── mac/                             Apple Silicon 专用
├── win/                         Windows GPU 专用
├── wifi-crack-notebook/             引擎与历史路径（Mac/云脚本本体）
│   └── dicts/                       真实字典文件所在（大文件）
└── wifi-crack-kali/                 抓包与攻击
```

## 字典 `shared/dicts/`

| 类别 | 示例 | 说明 |
|------|------|------|
| 规则 | `china-wifi.rule` | 中国场景变换 |
| 掩码 | `00-china-wifi-masks.hcmask` | 结构穷举 |
| 高频 | `wpa-top4800.txt` `probable-wpa.txt` | 快速阶段 |
| 中国 | `cn-top100w.txt` `05-chinese-full-410w.txt` … | 结构语料 |
| 新下载 | `cn-sources/latest/` | 全网新源；`merged/cn-wifi-quickhit-8plus.txt` 为 8–63 合并包 |
| 巨型 | `15-mega160m.txt` 等 | 本地保留，**默认不入 Git** |

脚本**启动时自动读取**该目录（Mac `crack.sh` / Windows `crack.ps1` / `crack_local.sh`）。

自定义：

```bash
# Mac
bash mac/crack.sh --dict-dir /path/to/dicts
```

```powershell
# Windows
.\win\crack.ps1 -DictDir D:\my-dicts
```

## 握手包 `shared/captures/`

支持扩展名：

- `.hc22000` / `.22000`（推荐）  
- `.cap` / `.pcap` / `.pcapng`（需本机有 `hcxpcapngtool`）

也可运行时指定，**不必**放进默认目录：

```bash
bash mac/crack.sh --hash ./a.hc22000 --cap ./b.cap
```

```powershell
.\win\crack.ps1 -Hash .\a.hc22000 -CaptureDir D:\hs
```

- 完整爆破包：微信备注 `wifi破解（github）` 获取
